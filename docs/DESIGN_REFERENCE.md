## 1. 設計語言

**「風車工作台」**：明亮、通透、帶一點玻璃質感的 macOS 風格。

- 底色是乾淨、偏冷的中性色，讓**七個工具各自的顏色當主角**。
- 進入某個工具時，整個介面的**強調色**（主按鈕、焦點環、滑桿、進度條、氛圍光）會在 **400 ms** 內平滑換成該工具的顏色。
- 關鍵字：通透、輕盈、柔和的深度、克制但有驚喜。
- **刻意避免**：白底紫藍漸層的 AI 模板感、emoji 當圖示、霓虹、滿版高飽和色塊、過重陰影、擬物質感、假資料。
- 每個動畫都要能回答「它在告訴使用者什麼」（狀態改變、空間關係、因果），答不出來就不做。

## 2. 色彩

### 2.1 中性色（淺色／深色）

深色模式**不是單純反轉**：降低飽和、拉開層次、邊框改用半透明白。

| token           | 用途                           | 淺色                 | 深色                    |
| --------------- | ------------------------------ | -------------------- | ----------------------- |
| `bg`            | 視窗底色                       | `#F4F5F8`            | `#0A0C10`               |
| `surface`       | 卡片、面板                     | `#FFFFFF`            | `#12151B`               |
| `surface-2`     | 次層底色、輸入區、懸停底       | `#F0F2F6`            | `#181C24`               |
| `surface-3`     | 第三層、分段控制選取底（深色） | `#E7EAF0`            | `#20252F`               |
| `border`        | 一般邊框                       | `rgba(15,23,42,.08)` | `rgba(255,255,255,.08)` |
| `border-strong` | 輸入框、按鈕外框               | `rgba(15,23,42,.16)` | `rgba(255,255,255,.16)` |
| `text`          | 主文字                         | `#0F172A`            | `#F3F5F9`               |
| `text-2`        | 次要文字                       | `#4B5568`            | `#A6AFC0`               |

### 2.3 七個工具的顏色

每個工具有四個強調色角色：

- `m-1 → m-2`：圖示方塊漸層（135°）。
- `accent`：圖形元件（滑桿、進度、焦點環、選取線），在 surface 上對比 ≥ 3:1。
- `accent-strong`：**主按鈕底色**，配白字對比 ≥ 4.5:1（部分工具色太亮，所以另外定義較深的變體）。
- `accent-ink`：強調**文字**與連結，在 surface 與 bg 上對比都 ≥ 4.5:1。

### 2.4 衍生色規則

- 氛圍光、陰影、發光一律從 `m-1`／`m-2`／`accent` 用 `color-mix()` 衍生，不另外寫死色碼。常用比例：
  - 選取／高亮底：`accent 12%` 透明（例如選單項目、指令面板選取 pill、圖示底）。
  - 徽章底：`accent 14%`、成功 `14%`、警告 `16%`、危險 `14%`。
  - 焦點光暈：`accent 22%`，3 px 外擴。
  - 拖放區拖入時：底色 `accent 7%` 混入 surface，外圈 `accent 16%` 4 px，加 `0 20px 60px -20px accent 55%` 光暈。
  - 文字選取：`accent 25%`。
  - 中性懸停底：`text 5–6%`。
- 主按鈕陰影：`0 6px 16px -6px accent 70%`＋頂部 `inset 0 1px 0 rgba(255,255,255,.18)`。
- 圖示方塊陰影：`0 6px 16px -4px m-2 50%`。

### 2.5 強調色換色

`--accent`、`--accent-2`、`--accent-strong`、`--accent-ink`、`--m-1`、`--m-2` 以 CSS `@property` 註冊成顏色型別，在 `<html>` 上以 **400 ms `cubic-bezier(.2,0,0,1)`** 過渡。所有使用強調色的元素（按鈕、滑桿、氛圍光）會同步漸變，而不是瞬間跳色。

> **macOS 對應**：把工具色定義成 `Color`／`NSColor` 資產（Any／Dark 兩組），用一個 `@Environment` 或 `@Observable` 的 `accentRole` 驅動；切換工具時以 `withAnimation(.timingCurve(0.2, 0, 0, 1, duration: 0.4))` 改變。AppKit 可用 `NSAnimationContext` 對 `CALayer` 的 `backgroundColor` 做隱式動畫。

## 3. 字型與排版

### 3.1 字型堆疊

```
英數：Inter（可變字重，自架）
中文：PingFang TC（蘋果裝置原生）→ Noto Sans TC（思源黑體，自架、依字元範圍分段下載）→ Microsoft JhengHei → system-ui
等寬：ui-monospace, "SF Mono", Menlo, Consolas, monospace
```

- 蘋果裝置直接用系統蘋方；其他平台用外觀最接近蘋方的思源黑體。
- 匯出的 PDF（文字轉 PDF）內嵌思源黑體 400／700 子集（蘋方授權不允許嵌入）。
- **macOS 原生版直接用 SF Pro＋PingFang TC 即可**，這正是網頁版想模仿的效果。

### 3.2 字級表

| 用途                       | 大小／行高            | 字重     | 其他                   |
| -------------------------- | --------------------- | -------- | ---------------------- |
| display（首頁主標）        | 40／48（手機 32／40） | 700      | 字距 −0.02em           |
| h1（頁標題）               | 28／36                | 600      | 字距 −0.01em           |
| h2（區塊標題、對話框標題） | 20／28                | 600      |                        |
| h3（卡片標題）             | 16／24                | 600      |                        |
| body                       | 14／22（手機 15／24） | 400      |                        |
| small（標籤、輔助）        | 13／20                | 400／500 | 表單標籤 500、`text-2` |
| caption（徽章、提示）      | 12／16                | 500      |                        |
| kbd（按鍵）                | 11／16                | 500      | 底邊框 2 px            |

### 3.3 排版細節

- 標題 `text-wrap: balance`（避免最後一行只剩一個字），內文 `text-wrap: pretty`。
- **等寬數字只用在數值**（時間碼、檔案大小、進度、速度、計數）。不要全域開啟：Inter 的 `tnum` 會把連字號也變等寬，「sample-clip」會看起來像「sample - clip」。
- **長檔名一律中段省略並保留副檔名**：前段 truncate，尾段固定顯示「最後 8 字＋副檔名」，例如 `IMG_20260930_…_final.heic`。螢幕閱讀器讀完整檔名。保留檔名中的空白（不可被折疊）。
- 中文使用全形標點（，。：；？！）與「」。

> **macOS 對應**：`Text(...).monospacedDigit()` 只套在數值；檔名用 `.truncationMode(.middle)`，但要自行保證副檔名可見（NSTextField 的 middle truncation 不保證保留副檔名，建議手動拆成兩段 HStack，前段 `.truncationMode(.tail)`、後段 `.fixedSize()`）。

### 4.1 圓角

| token    | px           | 常用於                            |
| -------- | ------------ | --------------------------------- |
| xs       | 6            | Kbd、色票、小標籤                 |
| sm       | 8            | 小按鈕（h32）、選單項目、Tooltip  |
| md       | 12           | 一般按鈕（h40）、輸入框、導覽項目 |
| lg       | 16           | 卡片、浮層、Toast、大按鈕（h48）  |
| xl       | 22           | 大區塊                            |
| 2xl      | 28           | 拖放區、手機底部抽屜頂角          |
| 圖示方塊 | 邊長 × 22.5% | 28→6.3、40→9、56→12.6、72→16.2    |

間距以 **4 px 網格**為基礎。

### 4.2 陰影（elevation）

| 層級                  | 淺色                                                                | 深色                                         |
| --------------------- | ------------------------------------------------------------------- | -------------------------------------------- |
| e1（卡片靜止）        | `0 1px 2px rgba(15,23,42,.06), 0 1px 1px rgba(15,23,42,.04)`        | `0 1px 2px rgba(0,0,0,.5)`＋內側高光         |
| e2（按鈕、把手）      | `0 4px 12px -2px rgba(15,23,42,.08), 0 2px 4px rgba(15,23,42,.04)`  | `0 6px 16px -4px rgba(0,0,0,.6)`＋內側高光   |
| e3（卡片懸停、Toast） | `0 12px 32px -8px rgba(15,23,42,.14), 0 4px 8px rgba(15,23,42,.05)` | `0 16px 40px -10px rgba(0,0,0,.7)`＋內側高光 |
| e4（浮層、對話框）    | `0 24px 64px -12px rgba(15,23,42,.28)`                              | `0 28px 72px -12px rgba(0,0,0,.8)`＋內側高光 |

深色的「內側高光」＝ `inset 0 1px 0 rgba(255,255,255,.04)`（e4 為 `.05`）。淺色玻璃的內側高光為 `rgba(255,255,255,.6)`。

### 4.3 玻璃材質

```
背景：surface 72% 透明
模糊：blur(24px) saturate(160%)
邊框：1px border
內側高光：inset 0 1px 0（淺色 rgba(255,255,255,.6)／深色 .04）
```

- 用在：側欄、頂欄、手機底部 tab bar、任務中心膠囊。
- 浮層（Popover、選單、對話框、指令面板、任務面板）用「floating」變體：surface **86%** 透明、同樣模糊、e4 陰影、圓角 16。
- Toast：surface **90%**、`blur(20px)`、e3。
- 底部抽屜：surface **92%**。
- 不支援背景模糊時退回實色 surface。

### 4.4 焦點環

- 只在鍵盤操作時顯示（`:focus-visible`）。
- 2 px `accent` 外框＋2 px 間隔（outline-offset 2）。
- 輸入框聚焦：邊框變 `accent`，外加 `0 0 0 3px accent 22%` 光暈。

### 4.5 捲軸

細（10 px 軌道、3 px 透明邊＝實際約 4 px）、圓角、`text 18%`，懸停時加深到 `32%`。

> **macOS 對應**：玻璃直接用 `NSVisualEffectView`（`.sidebar`／`.headerView`／`.popover`／`.hudWindow`）或 SwiftUI `.background(.regularMaterial)`；陰影層級可對應成 4 組 `shadow(color:radius:y:)`。

## 5. 動態系統（motion token）

所有時間、曲線、彈簧都集中在 `src/design/motion.ts`，**元件裡禁止寫死魔術數字**，CSS 端有同名變數並以測試確認一致。

### 5.1 時間

| token   | ms  | 典型用途                                                |
| ------- | --- | ------------------------------------------------------- |
| instant | 90  | 浮層關閉、Tooltip 連續顯示、按鈕縮放回彈                |
| fast    | 160 | 懸停、顏色變化、分頁內容交叉淡化、頁面退場              |
| base    | 240 | 頁面淡入、側欄寬度、背景淡入、卡片懸停                  |
| slow    | 360 | 3D 傾斜回正                                             |
| slower  | 560 | 主標逐詞揭示、主題切換圓形揭示、完成光環、Logo 懸停旋轉 |
| hero    | 900 | Logo 組裝                                               |
| accent  | 400 | 強調色換色、勾勾描繪                                    |

### 5.2 緩動曲線

| token      | cubic-bezier       | 用途                                                            |
| ---------- | ------------------ | --------------------------------------------------------------- |
| standard   | `(.2, 0, 0, 1)`    | 大部分淡入淡出與顏色過渡                                        |
| decelerate | `(.05, .7, .1, 1)` | 進場、光環擴散                                                  |
| accelerate | `(.3, 0, .8, .15)` | 退場（頁面離開、浮層關閉）                                      |
| emphasized | `(.16, 1, .3, 1)`  | 有份量的位移：側欄寬度、逐詞揭示、主題揭示、Logo 旋轉、浮層彈出 |

### 5.3 彈簧

| token  | stiffness | damping | mass | 手感             | SwiftUI 換算（response／dampingFraction）        |
| ------ | --------- | ------- | ---- | ---------------- | ------------------------------------------------ |
| snappy | 520       | 38      | 0.9  | 快、幾乎不回彈   | `.spring(response: 0.26, dampingFraction: 0.88)` |
| smooth | 300       | 30      | 1    | 標準位移         | `.spring(response: 0.36, dampingFraction: 0.87)` |
| gentle | 180       | 24      | 1    | 柔和進場         | `.spring(response: 0.47, dampingFraction: 0.89)` |
| bouncy | 420       | 20      | 1    | 明顯回彈（強調） | `.spring(response: 0.31, dampingFraction: 0.49)` |

換算公式：`response = 2π / √(k/m)`、`dampingFraction = c / (2√(k·m))`。也可直接用 `.interpolatingSpring(mass:stiffness:damping:)` 填原值。

**選用原則**：位移與縮放用彈簧、淡入淡出用曲線；選取指示（pill、底線、Switch）用 snappy；一般進場與佈局變化用 smooth；清單 stagger 進場用 gentle；完成勾勾、徽章、強調物件彈入用 bouncy。

## 7. 背景氛圍

- 底色 `bg` 上放 **3 顆大型模糊色塊**（`radial-gradient` 從色到透明＋`blur(40px)`），淺色透明度 **.10**、深色 **.16**。

- **首頁**用三個工具色（播放器藍、GIF 洋紅、圖片互轉綠）；**工具頁**用該工具的 m-1／m-2，換工具時色塊顏色 400 ms 漸變。

- 分頁隱藏時暫停漂移；動畫強度「精簡／關閉」時停止漂移。

> **macOS 對應**：視窗內容背後放 3 個 `Circle().fill(RadialGradient).blur(radius: 40)`，用 `TimelineView(.animation)` 或 `CAKeyframeAnimation` 做 60–90 秒的位移循環；視窗失焦或縮到 Dock 時暫停。

## 9. 全域轉場

### 9.1 換頁

- **舊頁**：淡出、縮小到 **0.98**、模糊 **4 px**，160 ms、accelerate 曲線。
- **新頁**：從下方 **12 px** 滑入（smooth 彈簧）＋淡入（240 ms、standard）。
- 兩頁同時存在，舊頁以絕對定位「彈出」，不佔版面、不造成跳動。
- 換頁時如果原本有捲動，舊頁會被平移補償，維持原本的視覺位置淡出，新頁從頂端開始。
- 換頁後焦點移到主內容（方便鍵盤與螢幕閱讀器）。

### 9.2 首頁卡片 → 工具頁（共享元素）

首頁卡片上的**圖示方塊與標題**，和工具頁頁首的圖示方塊與標題共用同一個 id，換頁時以 smooth 彈簧**飛到新位置並變換大小**；返回首頁時反向飛回卡片。

### 9.3 主題切換：圓形揭示

- 從切換按鈕的中心點，以 `circle(0 → r)` 的 clip-path 向外擴散，r＝到視窗最遠角落的距離。
- 560 ms、`(.16,1,.3,1)`。
- 不支援時（或動畫強度為精簡）退回 **200 ms 交叉淡化**（背景、文字、邊框顏色同步過渡）。
- 切換按鈕本身：太陽／月亮圖示以旋轉 ±90°、縮放 0.5 交替，160 ms。

### 9.4 強調色換色

見 2.5，400 ms。

### 9.5 側欄收合

- 寬度 248 ↔ 72，240 ms、emphasized。

- 新增：從縮放 0.96、透明以 smooth 彈入。
- 移除：縮小到 0.9＋淡出（160 ms），鄰近項以佈局動畫補位。

### 進度

- **進度條**：高 6（sm 為 4）、全圓角；確定進度以 smooth 彈簧**平滑插值**（不跳格），填色 `accent-2 → accent` 漸層；不確定進度用 1.2 秒的光帶 shimmer。
- **環形進度**：同樣彈簧插值；不確定時以 1 秒旋轉 70% 缺口的圓弧。
- **完成**：綠色圓形以 bouncy 從 0.5 彈出，白色勾勾 **path 描繪 400 ms**（emphasized、延遲 80 ms），同時一圈 2 px 綠色光環從 0.6 擴散到 1.7 倍並淡出（560 ms、decelerate），只播一次。

### 數字

節省容量、檔案大小、時間碼變化時，以 gentle 彈簧**滾動計數**到新值（精簡模式直接跳到結果）。

（本節內容整理自各工具的實作程式碼。）

### 12.1 媒體播放器（`features/player/`）

**招牌動畫**

- **播放／暫停 path 變形**：兩條 path 頂點數相同，直接內插路徑，spring.snappy。
  - 播放（三角形拆左右兩半）：`M7 4.5 L12.5 7.9 L12.5 16.1 L7 19.5 Z`、`M12.5 7.9 L19 12 L19 12 L12.5 16.1 Z`
  - 暫停：`M6.5 5 L10.25 5 L10.25 19 L6.5 19 Z`、`M13.75 5 L17.5 5 L17.5 19 L13.75 19 Z`
  - viewBox 24，預設 22 pt。
- **中央閃現圖示**：72 pt 玻璃圓，透明度 `[0,1,1,0]`、縮放 `[0.6,1,1.04,1.18]`、時間點 `[0,.25,.6,1]`，560 ms easeOut；內部 34 pt 圖示先顯示舊狀態、下一格畫面才切新狀態，讓變形看得到。
- **跳轉水波**：
  - 水波佔畫面左或右 42% 寬，內部圓形為 150% 寬、偏移 10%；縮放 0.4→1、透明度 .9→.5，560 ms emphasized；背景 `radial-gradient(白 16% → 白 4% 70%)`。
  - 「±N 秒」文字 22 pt 粗體：縮放 0.8→1、x ±8→0，spring.bouncy。
  - 三個箭頭依序閃：透明度 `[.25,1,.25]`，560 ms，間隔 80 ms。
  - 退場淡出 360 ms，800 ms 後清除；**800 ms 內同側連續跳轉會累加秒數**。
- **控制列淡出**：出現 160 ms、消失 360 ms，y 0↔8（smooth）；隱藏時不接收點擊。播放中閒置 **2.5 秒**隱藏；暫停、選單開著、播完時不隱藏；滑鼠離開畫面立即隱藏；閒置時游標隱藏。
- **時間軸**：
  - 懸停或拖曳時軌道 scaleY 1→1.75（160 ms emphasized）；軌道 4 pt、可點區 24 pt（有波形時 36）。
  - 把手 14 pt 白點＋3 pt 強調色 45% 光圈：平時 scale 0，懸停／拖曳／聚焦時 scale 1（160 ms）；觸控裝置常駐 0.85。
  - 時間浮標 x 以 spring.snappy 跟隨游標（兩端夾住縮圖半寬＋4）；出現時縮放 0.92→1、y 4→0。
  - 浮標上方縮圖 160×90（另一支隱藏影片 seek 後繪製，只保留最後一個請求，未就緒時透明度 .3）。
  - 懸停時以白 20% 預覽到游標位置；已播放部分 `accent-2 → accent` 漸層；章節分隔線 3 pt。
- **A–B 漸層條生長**：scaleX 0→1、透明度 0→.9（gentle、左側為原點）；退場 160 ms；光暈 `0 0 0 1px accent 60%, 0 0 14px accent 55%`；A／B 把手 scale 0→1、y 6→0（bouncy），高 20（觸控 28）。
- **截圖**：白色閃光 .55→0（360 ms）；縮圖卡從畫面中央縮進右上角（縮放 2.4→1、位移 −20%／20%→0，smooth），寬 `min(260, 62%)`；8 秒沒互動自動收起（懸停時暫停計時）。
- **其他**：
  - OSD 提示：玻璃膠囊從 y −8、縮放 .96 以 snappy 出現，1.26 秒後消失。
  - 長按 2 倍速徽章：從上方 8 pt 彈出。
  - 緩衝轉圈：延遲 240 ms 才出現（避免閃爍）。
  - 大播放鍵：72 pt 玻璃圓，以 bouncy 從 .7 出現，懸停 1.06、按下 .94；只在暫停且位於開頭或結尾時顯示。
  - 全螢幕清單抽屜：從右側 24 pt 滑入（smooth）。
  - 目前曲目底色以共享佈局滑動（snappy）；清單中正在播放的項目有三根等化器長條（scaleY .25→1 交替，900／700／1100 ms，錯開相位），暫停時凍結。
- **音訊視圖**：
  - 換曲交叉淡化 560 ms；封面縮放 .9→1、y 8→0，標題延遲 90 ms 上升。
  - 背景是封面放大 125%、高度模糊、透明度 45%。
  - 頻譜：長條數 = clamp(16, 寬/14, 64)，間隔 4 pt，每格衰減 ×0.86；暫停後以 ×0.9 慢慢落下，全部歸零才停止繪製；另有波形模式（線寬 2.5、光暈 12）。
- **字幕**：控制列出現時字幕上移（避開 96 pt 控制列），360 ms standard；字級 `scale × clamp(14, 3.4% 寬, 46)`。

**互動與手勢**

- 長按 500 ms：2 倍速，放開恢復；移動超過 6 pt 取消長按。
- 觸控雙擊（350 ms 內、同一半邊）：左 −10 秒、右 +10 秒＋水波；觸控單擊等 350 ms 後切換控制列。
- 觸控水平拖曳（位移 >12 且水平 > 垂直×1.2）：滑過整個寬度最多 90 秒，顯示時間浮窗。
- 滑鼠：單擊播放／暫停、雙擊全螢幕。
- 時間軸鍵盤：←↓ −5 秒、→↑ +5 秒（Shift 10 秒＋水波）、PageUp／PageDown ±10%、Home／End；拖曳時暫停、放開後恢復。
- A／B 把手：方向鍵 ±0.1 秒（Shift ±1）。
- 快捷鍵：Space／K、←→（Shift ±10）、J／L、↑↓ 音量 ±5%、M、F、`,` `.` 逐格、`[` `]` 速度、A／B、0–9 跳到 0–90%、P、S、I、Esc（依序關閉抽屜、截圖、資訊）。
- 版面：畫面 16:9（音訊 16:10），手機 16:11（音訊 4:5）；控制列按鈕依容器寬度逐步出現（上一首／下一首 → ±10 → 音量滑桿 → 截圖與子母畫面）；按鈕 40 pt、觸控 44 pt；播放器畫面在深淺色都用深色。

> **macOS 對應**：路徑變形可用自訂 `Shape` 的 `animatableData`；控制列閒置隱藏搭配 `NSCursor.setHiddenUntilMouseMoves(true)`；音量 >100% 用 `AVAudioEngine` 的增益節點。

### 12.2 螢幕錄影（`features/recorder/`）

**招牌動畫**

- **3‑2‑1 倒數**：
  - 全螢幕遮罩 `rgba(10,12,16,.42)`＋10 pt 模糊，淡入 240 ms、淡出 160 ms。
  - 環形 220×220、半徑 92、線寬 8；底圈白 16%、前景 accent‑2 圓頭，3 秒線性從頂端繞完。
  - 中央光暈 accent 22% 模糊。
  - 數字 112 pt 粗體：從 **縮放 1.6** 以 bouncy 落到 1，離場縮到 0.5（160 ms）。
  - Esc 取消；「立即開始」按鈕預設聚焦。
- **紅點呼吸**：12 pt 紅點 `breathe` 1.6 秒；外圈擴散 1.6 秒（縮放 1→2.4、透明度 .55→0）；暫停時紅點變灰、停止擴散。
- **HUD 膠囊變形成結果卡**：膠囊（高 56、圓角 28，從 y 24、縮放 .92 以 smooth 出現）與結果卡（圓角 16）共用同一個共享元素 id，停止錄影時**膠囊直接變形放大成結果卡**、圓角同步內插；卡內影片延遲 160 ms 淡入。HUD 固定在底部置中，避開側欄與手機 tab bar。
- **HUD 細節**：按鈕 44（桌機 40），按下 .9；暫停／繼續圖示以旋轉 −45°→0、縮放 .6 交換；標記數徽章每次 +1 都以 bouncy 重新彈出；「已加標記」泡泡 1.2 秒後消失；麥克風電平 5 根。
- **浮動控制視窗（PiP）**：420×88，複製主視窗的主題與動畫設定。
- **鏡頭泡泡**：以 bouncy 從 .6 出現，拖曳時 1.04；大小 12%–45% 畫面；方向鍵 1%（Shift 5%）、+／− 每次 2%。
- **其他**：來源卡 stagger（50 ms 起、每張 40 ms）；錄影庫卡片 stagger＋佈局動畫，刪除時縮到 .92。

**狀態與互動**

- 準備 → 倒數（疊在上方）→ 錄製中 → 結果，同一容器佈局動畫＋三步 Stepper。
- 錄製中分頁標題顯示「● 00:12 · 原標題」，暫停時「❚❚」。
- 快捷鍵：R 開始／停止、P 暫停、M 靜音、T 標記、Esc 取消倒數。

> **macOS 對應**：使用 ScreenCaptureKit；HUD 用不搶焦點的浮動 `NSPanel`，停止時可把 HUD 的 frame 動畫到結果視窗的位置，再交叉淡化，模擬變形效果；menu bar 顯示錄影中紅點與計時。

### 12.3 GIF 製作（`features/gif/`）

**招牌動畫**

- **膠卷縮圖翻入**：每格透視 400；縮圖從 rotateY −80°、縮放 .9、透明以 smooth 翻到 0°（原點在左緣），透明度 160 ms。縮圖本來就依序產生，所以自然逐格翻入；一次到齊時補 40 ms stagger。膠卷高 56，格間 1 pt 黑 20% 分隔線。
- **區間吸附**：拖曳靠近整數秒時吸附，門檻 `min(0.08, max(0.03, 長度×0.004))` 秒；吸附瞬間在該刻度閃一條 3 pt 強調色光條（上下各多 6 pt、12 pt 光暈），透明度 .95→0、scaleY 1.15→1，560 ms decelerate。鍵盤以 0.1 秒微調不吸附；最小區間 0.1 秒；區間長度數字以彈簧滾動。
- **編碼中的「正在寫入影格」**：一張 168 pt 寬的即時預覽浮在膠卷上方（2 pt 強調色外框），以 smooth 彈簧沿膠卷移動到目前處理的時間點；右上角 36 pt 進度環＋百分比；下方 18 pt 指針；區間外遮暗。
- **完成**：預覽與結果卡共用共享元素 id，**從小預覽以彈簧放大成結果卡**；結果卡內 SuccessCheck，統計格以 stagger（150 ms 起）上升。
- **其他**：選項晶片以共享 pill 滑動；裁切角把手 16 pt，懸停放大 1.25。

**互動**：Space 預覽、I／O 設起點／終點、⌘Enter 開始；裁切與文字框方向鍵 1%（Shift 5%）；圖片模式可拖曳排序（從落點飛入）；去背取色時十字游標；影格延遲最小 20 ms、步進 10 ms。

### 12.4 圖片互轉（`features/convert/`）

**招牌動畫**

- **縮圖 blur‑up**：載入前骨架；載入後透明度 0→1、縮放 1.08→1、模糊 14 pt→0，560 ms decelerate。
- **轉換中流動色光**：卡片外框有一圈 2 pt 寬的 conic 漸層（透明 → accent‑2 → accent → 透明）沿邊緣旋轉，1.6 秒一圈（只旋轉、不重繪）；同時加強調色光暈 `0 0 0 1px accent 18%, 0 10px 30px -14px accent 60%`，縮圖蓋 surface 45% 遮罩。
- **完成**：外框色光淡出（360 ms），**綠色勾勾描繪＋光環只在第一次完成時播放**（之後是靜態勾勾，離開再回來不重播）；節省百分比綠色徽章從 0 滾動計數到結果，只播一次；增加超過 10 倍時顯示「×倍數」。
- **卡片清單**：佈局動畫，從縮放 .96、y 8 以 smooth 進場，移除時縮到 .92；新卡片從落點飛入；容器寬 ≥ 640 改兩欄。
- **其他**：格式選擇以共享 pill 滑動；進階選項箭頭旋轉 180°（snappy）、內容展開下移 6 pt；選項變更後已完成的卡片標示「過期」並轉灰。

**互動**：⌘Enter 開始；貼上、加入資料夾、重複拖入；前後對比可切換「符合／100%／200%」，放大時像素不平滑（看得出細節）。

### 12.5 圖片工具（`features/tools/`）

### 12.6 QR Code（`features/qr/`）

**招牌動畫**

- **漣漪浮現**：每個模組依「到中心的距離（0–1）」延遲 `距離 × 360 ms` 出現，單點動畫 160 ms（從縮放 0、透明到 1，以各自中心縮放，emphasized），總長約 520 ms；模組超過 2500 個時改為 10 圈一圈一圈浮現（縮放 .94→1）。定位眼依距離延遲、中央 Logo 立即出現。**只在第一次出現內容與切換內容類型時播放**，打字修改內容時不重播。
- 預覽容器切換類型：縮放 .96→1（退場 1.02），240 ms emphasized；空狀態的 QR 圖示 2.7 秒呼吸。
- **掃描括號**：掃描框邊長＝短邊 × 64%；四角 L 形（臂長 28、線寬 4、圓頭、白色加陰影）以 2.7 秒呼吸（往中心靠 4 pt、透明度 .72）；掃描線 2 pt（白＋工具色漸層、14 pt 光暈）1.8 秒上下往返。
- **辨識成功**：括號以 snappy **收緊貼到 QR 實際位置**（外擴 8 pt、最小 56），變綠色（從 1.25 縮到 1，240 ms）；QR 區域閃一下綠光（透明度 0→.45→0、縮放 .92→1.04→1，560 ms）；外圍壓暗；觸覺回饋（手機震動 30 ms）；結果卡從縮放 .94、y 12 以 bouncy 彈出。
- 掃描節奏：每 90 ms 解碼一次；連續模式同一內容 2.5 秒內不重複；成功提示停留 900 ms；連續 4 格沒看到 QR 才算移開。
- **其他**：類型選擇以共享 pill 滑動；表單切換 160 ms；容量條 240 ms 平滑變長，超過 50% 變警告色、滿了變危險色；相機按鈕 48 pt、按下 .92。

**版面**：桌機預覽在右側 sticky；手機與平板在表單上方有**常駐精簡預覽列**（sticky、72／88 pt 縮圖＋下載鈕），點縮圖開底部抽屜看完整預覽。

**快捷鍵**：⌘S 下載 PNG、⇧⌘C 複製、⌘V 貼上圖片掃描；類型選擇支援方向鍵。

## 13. 動畫強度與無障礙

### 動畫強度（設定 → 外觀）

| 等級                                     | 行為                                                                                                                                             |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 完整（預設）                             | 全部動畫                                                                                                                                         |
| 精簡（系統偏好「減少動態效果」時的預設） | **保留淡入淡出與狀態變化**；移除位移、縮放、傾斜、共享元素、背景漂移、裝飾性循環動畫；錯誤抖動改成邊框閃紅；數字直接跳到結果；主題切換改交叉淡化 |
| 關閉                                     | 全部瞬間切換（CSS 動畫歸零、motion 直接跳到終點）                                                                                                |

由一個全域設定統一控制，元件不各自判斷。

### 無障礙

- 所有功能可只用鍵盤操作；焦點環清楚；對話框焦點鎖定、Esc 關閉。
- 進度用 `aria-live="polite"` 回報；選單、分頁、滑桿、進度條都有正確的角色。
- 觸控目標 ≥ 44 px；支援 200% 縮放。
- 尊重系統的減少動態效果、深淺色、提高對比設定。
- 對比度以自動化測試檢查（一般文字 ≥ 4.5:1、圖形 ≥ 3:1）。

> **macOS 對應**：讀取 `NSWorkspace.shared.accessibilityDisplayShouldReduceMotion` 與 `accessibilityDisplayShouldIncreaseContrast`；SwiftUI 用 `@Environment(\.accessibilityReduceMotion)`。
